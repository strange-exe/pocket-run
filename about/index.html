How it works

Three steps, the same on every phone.

  1. 1

    Open or type a file

    Pick a .py, .c or .cpp file from your phone, or start a new one. Your work is kept between visits.

  2. 2

    Press Run

    The code runs right in your browser, on your phone's own processor. C and C++ need a one-time download of about 20 MB.

  3. 3

    Save or share

    Save puts the file back in your downloads with the same name. Share makes a link anyone can open.

Safe with code from anyone

Students share code all the time. Pocket Run checks everything that comes in and keeps every program in a sandbox.

Nothing is uploaded
Your files stay on your phone. A share link carries the file in the part after #, which browsers never send to a server.
Programs are contained
A run stops after 8 seconds or 64 KB of output, and it can't reach the network or the app's own storage.
Disguised files are refused
Programs renamed to .py, hidden text-direction tricks and oversized links are blocked before they reach the editor.
Good to know
One file at a time, up to 512 KB, with each language's standard library. C++ exceptions aren't supported.
